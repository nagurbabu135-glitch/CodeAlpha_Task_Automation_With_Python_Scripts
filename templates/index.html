Welcome to AutoPy Playground!

This application implements the tasks specified in Task 3: Task Automation with Python Scripts. Select a task from the sidebar, configure parameters, and run it locally.

1. JPG Organizer

Finds and moves all .jpg files from a source directory to a target directory. Uses os and shutil libraries.

2. Email Extractor

Scans text files, extracts all email addresses, and writes them to an output file. Uses re (regex).

3. Web Title Scraper

Requests a webpage URL, parses its content to find the <title>, and saves the text to a file. Uses requests.

Fast testing using the Demo Workspace

Don't have directories or files ready to test? Click "Setup Demo Workspace" above. It will generate folders and dummy files inside the app's directory so you can test all three tools instantly.
